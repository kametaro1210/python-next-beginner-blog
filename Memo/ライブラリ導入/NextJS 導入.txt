
==================================================
Next.js 導入手順
==================================================

## 1. 前提

- Node.js がインストールされていること
- Next.js プロジェクトを作成するフォルダーでターミナルを開くこと
- プロジェクト名は小文字・数字・ハイフンを使用すること

### プロジェクト名の注意

npm の命名規則により、プロジェクト名に大文字は使用できない。

例:

```text
NG: NEXT-BLOG-TUTORIAL
OK: next-blog-tutorial
```

大文字を含むフォルダーを使用している場合は、親フォルダーで名前を変更する。

```powershell
cd ..
Rename-Item "NEXT-BLOG-TUTORIAL" "next-blog-tutorial"
cd "next-blog-tutorial"
```

## 2. Next.js のインストール

以下のコマンドを実行する。

```bash
npx create-next-app . --use-npm
```

## 3. 開発サーバーの起動

インストール完了後、以下のコマンドを実行する。

```bash
npm run dev
```

## 4. ブラウザーで確認

開発サーバー起動後、以下の URL をブラウザーで開く。

http://localhost:3000

## 5. 開発サーバーの停止

ターミナルで `Ctrl + C` を押す。
