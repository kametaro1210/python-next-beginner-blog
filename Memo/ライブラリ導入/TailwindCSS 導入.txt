==================================================
TailwindCSS 導入手順
==================================================

## 1. 前提

- Next.js プロジェクトを作成済みであること
- プロジェクトのフォルダーでターミナルを開くこと

## 2. TailwindCSS のインストール

プロジェクトのフォルダーで以下のコマンドを実行する。

```powershell
npm install -D tailwindcss @tailwindcss/postcss postcss
```

## 3. CSS の設定

`app/globals.css` の先頭に以下を記述する。

```css
@import "tailwindcss";
```

## 4. 動作確認

動作確認のため、`app/page.tsx` の中身をいったんすべて削除し、以下の内容に書き換える。

※これは TailwindCSS が適用されるかを確認するための一時的な変更である。
確認後は、元の内容に戻してもよい。

```tsx
export default function Home() {
	return (
		<h1 className="text-3xl font-bold underline">
			Hello, TailwindCSS!
		</h1>
	);
}
```

## 5. 開発サーバーの起動

```powershell
npm run dev
```

ブラウザーで以下の URL を開く。

http://localhost:3000

画面に大きく太字で下線付きの文字が表示されれば、TailwindCSS の導入は完了。

## 補足

`create-next-app` 実行時に Tailwind CSS を `Yes` にした場合は、すでに導入済みのため、追加インストールは不要。
